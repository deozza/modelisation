# Exercice 12 - états de l'eau

L'eau peut exister dans 4 états différents. Ces états changent en fonction de la pression et/ou de la température.

Modéliser ces changements via un diagramme de machine à états selon le fonctionnement suivant :

- liquide
  - vaporiser => gazeux
  - geler => solide
- gazeux
  - condenser => liquide
  - se déposer => solide
  - ionizer => plasmisque
- solide
  - réchauffer => liquide
  - sublimer => gazeux
- plasmique
  - déioniser => gazeux
