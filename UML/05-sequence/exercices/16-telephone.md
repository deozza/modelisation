# Exercice 16 - téléphone

Réaliser le diagramme de séquence pour la fonctionnalité suivante :

- un acteur allume son téléphone
- le téléphone fait sonner la tonalité de la ligne
- l'acteur compose un numéro sur le téléphone
- le téléphone fait sonner la tonalité du numéro
- le téléphone fait sonner du destinataire
- le destinataire décroche
- la sonnerie du destinataire s'arrête
- la tonalité de l'acteur se coupe
